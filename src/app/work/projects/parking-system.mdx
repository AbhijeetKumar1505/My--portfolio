## Overview

A modern web-based parking management system that manages parking lots, handles reservations, and provides real-time analytics for administrators.

Built with **Flask**, **SQLAlchemy**, and **SQLite**, with a Bootstrap 5 frontend and Chart.js dashboards.

## Features

### For users
- View available parking spots in real time
- Make instant reservations and review parking history
- Manage vehicle information
- Get parking duration estimates
- Browse lot locations, pricing, and spot availability

### For administrators
- Real-time occupancy monitoring and revenue tracking
- Peak-hours analysis and parking-duration distribution
- Active user and reservation monitoring
- Full parking-lot management: add/edit/delete lots, set hourly pricing, manage spots
- Occupancy-rate and revenue-by-lot analytics over time

## Tech stack

| Layer | Technology |
|-------|------------|
| Backend | Python 3.x, Flask, SQLAlchemy |
| Database | SQLite |
| Frontend | HTML5/CSS3, JavaScript, Bootstrap 5 |
| Analytics UI | Chart.js, DataTables, Font Awesome |

## Database schema

Key tables: **users**, **parking_lots**, **parking_spots**, **reservations**, **vehicles**.

## Architecture

Controllers handle routes and business logic; models define the schema; Flask-Migrate manages migrations; Jinja templates power separate admin and user UIs under `templates/admin` and `templates/user`.
